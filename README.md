# Мобільний додаток на React Native

## Опис

Найпростіший мобільний додаток, створений за допомогою React Native, з трьома екранами:
- Новини
- Фотогалерея
- Реєстрація

## Інструкція по запуску

1. **Встановлення залежностей:**
   ```bash
   npm install
   ```

2. **Запуск на емуляторі Android:**
   ```bash
   npx expo start --android
   ```

3. **Запуск на емуляторі iOS:**
   ```bash
   npx expo start --ios
   ```

4. **Запуск в режимі розробки:**
   ```bash
   npx expo start
   ```
