# Лабораторна робота №3 - Gesture Clicker

Мобільна гра-клікер з використанням різних типів жестів та системи відстеження прогресу виконання завдань.

## Інструкція по запуску

1. Клонувати репозиторій:
   ```bash
   git clone https://github.com/ipz234kbb1/MobileLabsRN2025.git
   cd MobileLabsRN2025
   git checkout Lab3
   ```

2. Встановити залежності:
   ```bash
   npm install
   ```

3. Запустити проект:
   ```bash
   npm start
   ```

4. Для запуску на емуляторі або фізичному пристрої:
   - Натисніть `a` для запуску на емуляторі Android
   - Натисніть `i` для запуску на емуляторі iOS
   - Відскануйте QR-код в Expo Go на фізичному пристрої

## Функціональність

- Різні типи жестів: 
  - Одиночний дотик (+1 очко)
  - Подвійний дотик (+2 очка)
  - Довге натискання (+5 очків)
  - Свайп вліво/вправо (+1-10 випадкових очків)
  - Масштабування (+3 очка)
- Система завдань з відстеженням прогресу
- Відображення виконання завдань в окремому розділі
- Анімації для кращого UX

## Використані технології

- React Native
- Expo
- React Navigation (Bottom Tabs)
- React Native Gesture Handler
- Context API для управління станом
